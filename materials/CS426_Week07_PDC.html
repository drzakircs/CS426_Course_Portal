Amdahl’s Law · formula

S(p) = 1f + (1 − f)/p
f = serial fraction; 1 − f = parallel fraction; p = processors.
f = 0
The whole program is ideally parallelizable.
f = 0.20
20% serial; 80% parallel.
f = 1
The program is entirely serial.

OpenMP · one loop, four workers

// C / C++ using OpenMP
int sum = 0;
#pragma omp parallel for num_threads(4) reduction(+:sum)
for (int i = 0; i < n; ++i) {
    sum += values[i];
}
parallel for
Distribute loop iterations.
reduction(+:sum)
Combine thread-local partial sums.
Important
Each iteration should be safe to execute independently.
Compiler
OpenMP support must be enabled.
Why should we use reduction rather than an unsynchronized shared sum?
✓A reduction avoids a race on the shared accumulator and combines partial sums correctly.
?
