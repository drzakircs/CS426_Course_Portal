What exactly is MPI?

MPI is an interface standard
A defined set of communication routines for coordinating processes.
An MPI implementation
Software such as Open MPI provides libraries and runtime tools.
What MPI is not
MPI is not the same thing as a programming language or a shared-memory thread.
Think: standardized interface → implementation → executable MPI application.

Blocking: what does it actually mean?

Blocking receive
MPI_Recv returns after the receive operation completes. Until then the caller may wait.
Blocking send
MPI_Send returns when its send buffer can safely be reused—not necessarily after the receiver finishes.
Blocking refers to completion conditions of that MPI call, not a guarantee of network simultaneity.

How communication affects performance

Message volume
More transferred bytes can increase communication time.
Message count
Many tiny messages can increase per-message overhead.
Synchronization
Some operations make processes wait.
Load balance
A slow rank can delay collective progress.
Why might 16 MPI ranks fail to beat 4 MPI ranks?
Answer: Extra communication, coordination overhead, and poor workload balance can offset the benefit of more parallel workers.
