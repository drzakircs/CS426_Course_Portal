# Learning Materials Directory

Upload weekly HTML learning material into this directory.

The course portal detects the week number from the filename. Supported examples include:

- `CourseName_Week1.html`
- `CourseName_Week01.html`
- `CourseName_Week_01.html`
- `CourseName_Week-01.html`
- `CourseName_week 01.html`
- `CourseName_Week02_Lecture.html`
- `CourseName_Week02_CodeExamples.html`
- `CourseName_Week02_Practice.html`

Multiple HTML files may be uploaded for the same week. The portal sorts them naturally by filename and shows all of them under that week's **Learning Material** area.

Do not rename this directory unless you also update `MATERIALS_DIR` in `assets/js/app.js`.
